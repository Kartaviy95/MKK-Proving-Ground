# Описание

Модуль теста пробития MKK Proving Ground: выбор техники и боеприпаса, создание тестовой цели, orbit-камера, тестовый projectile, отчет по damage/hitpoints/crew и инструмент “Создать взрыв” для создания взрывных `CfgAmmo` по клику на карте. Инструмент взрыва показывает локальную точку текущего положения, ставит глобальные черные маркеры “Взрыв” в местах клика и позволяет удалять их через Delete на карте инструмента, Delete на обычной карте или кнопку очистки.
