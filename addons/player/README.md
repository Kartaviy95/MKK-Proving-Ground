# mkk_ptg_player

Локальные инструменты игрока для полигона:

- бесконечные патроны для оружия игрока;
- режим бога с optional ACE medical wound handler, полным лечением и подавлением
  ACE Medical Feedback, unconscious/incapacitation, хромоты, Hearing, Fire,
  flashbang, G-Forces и Advanced Fatigue эффектов, без расхода vanilla/ACE
  stamina;
- `allowDamage false` для занятой техники с восстановлением ее прежнего состояния
  при выходе или отключении режима бога;
- резервный автоматический ремонт занятой техники, включая общий урон и damage
  всех hitpoints.
