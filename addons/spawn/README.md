# Описание

Глобальный спавн техники, водителей/экипажей, тестовых целей и быстрого маркера на карте, реестр созданных объектов, удаление целей и очистка полигона без обязательной загрузки аддона на dedicated server.

Сущности, которые PTG должен уметь удалять, получают публичный маркер `mkk_ptg_spawnedByPTG`. Очистка и удаление целей удаляют только такие сущности, даже если объект найден через общий runtime-скан, а не через локальный реестр.

Быстрый маркер на карте создает глобальный `mil_dot` marker и smoke shell в выбранной точке. Marker автоматически удаляется через 3 секунды; smoke shell живет по обычным правилам движка.

Спавн техники поддерживает пустую технику, полный экипаж через `createVehicleCrew` с опциональным переводом экипажа в выбранную сторону RED/BLUE/GREEN и режим “создать с экипажем”, где создается только водитель классом игрока для клиентского режима водитель+стрелок.

Тестовые цели в режимах наземной и воздушной техники передают выбранную сторону экипажа RED/BLUE/GREEN в общий `spawnCrew`; режим ботов выбирает сторону через конкретный класс бота.
